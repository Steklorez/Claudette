"Claude Code reads a Foundry API key only from its environment, so Deventry puts this key in the environment of the claude that each of this account's tabs runs. Every command Claude runs there inherits it: its Bash commands and scripts, hooks, MCP servers, and anything they start. Any of them can read the key, and print, log or send it on, and a prompt that tells Claude to read it gets it. Deventry keeps it in Test Keychain otherwise, never in its own files, a command line or a log. Where you can, sign in another way instead: Microsoft Entra ID (az login)."
