# Permissions and prompts

Claude Code stops and asks you things: whether it may run a command or edit a file, a question with options to pick from, a plan to approve, a form an MCP server wants filled in. This chapter covers each of these cards, the permission modes that decide what Claude Code asks about at all, and the question Claudette asks before Claude Code first works in a folder.

What counts as a permission, and the rules and modes behind it, are Claude Code's own: see [Claude Code's permissions docs](https://code.claude.com/docs/en/permissions). The pages here say what Claudette shows of them and how you answer.
