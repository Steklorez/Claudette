# Project tools

A tab can do things for the project in its folder: launch the editor, build, generate project files, open the solution, run your own commands, open your own links. This chapter covers the project row at the foot of the sidebar and its menu, the runs and the Project page, what Claudette knows about Unreal Engine, Unity and Godot projects, the actions and links you add yourself, and keeping Perforce logins fresh.
