# Usage and limits

Claudette's main job beyond the tabs is to show how much of your Claude plan's limits you've used, how fast, and when you'll run out, without you running `/usage`. This chapter covers the meters in the header and the charts behind them, what each tab has used, the warnings, what happens when a limit stops a task, and the history Claudette keeps so it can draw all of it.

Usage here means your Claude plan's limits. If a tab runs under an API key instead, it has no plan limits, and the header shows that key's estimated spend: see [Accounts](../accounts/index.md).
