# Threads

One task spread over several tabs in a project used to mean copying prompts into each tab and their replies back. A thread does that for you: a tab whose Claude hands work to other tabs in its folder group, its sub-threads, and gets their results back, while each stays a whole tab you can watch, steer and answer.

This chapter covers what threads are, how to set one up, how work goes out and reports come back, how you answer a sub-thread's questions, and how Claude can reach any other Claude Code session on your computer.
