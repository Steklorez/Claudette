# Tabs and sessions

A tab is one Claude Code session, run as its own `claude` process in a working folder. Claudette keeps the tabs in a sidebar, grouped by folder, and a panel beside the conversation shows what the selected tab is doing.

This chapter covers how tabs are opened, grouped, named, marked and closed; what a tab's row, menu and info card show; the settings a single tab can have of its own; the side panel and its pages (changed files, agents, processes, MCP servers and the rest); showing tabs side by side; the command palette; tabs that work in a git worktree; and what comes back when Claudette starts again.
