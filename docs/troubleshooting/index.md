# Troubleshooting

What to do when something goes wrong: Claude Code that can't be found or is too old, a sign-in that won't finish, a tab that won't start or seems stuck, a program Claude can't find, features missing on Linux, and Claude itself having a bad day. The last pages cover the logs and diagnostics to look at, what to include when you report a problem, and what to do with a settings file that won't load.

Start with the page that matches what you see. If none does, [Diagnostics and logs](diagnostics-and-logs.md) says where to look next, and [Reporting an issue](reporting-an-issue.md) says how to tell us.
