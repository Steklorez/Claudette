# Reviewing changes

Claudette keeps track of every file Claude changes in a session and what each one held before. This chapter shows how to see them all in one list, read a file's changes in the diff view, tick files off as you review them, put a change back, look at what a single turn did, and open diffs in your own diff tool. To read and edit the files themselves, see [Project files](../project-files/index.md).
