# Getting started

This chapter takes you from nothing to a working tab. It covers what Deventry needs, installing it (building it, on Linux), the first launch and signing in, opening your first tab, and a tour of the window. It ends with how Deventry uses Claude Code, so you know what is yours and what is Claude Code's, and how to run Deventry from its source.

Start with [What you need](what-you-need.md). On Linux, [Installing on Linux](installing-on-linux.md) has everything from start to finish. If Deventry is already installed, [A tour of the window](a-tour-of-the-window.md) names every part you see.
