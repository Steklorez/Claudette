# Accounts

{% include unreleased.html %}

Tabs run Claude Code under an account. Out of the box that's the one Claude Code is signed in to, as in a terminal. If you have a personal plan and a work API key, you can add the key to Claudette and choose, folder by folder and tab by tab, which account runs where.

This chapter covers your Claude sign-in and the header's account menu, adding API-key accounts, choosing a folder's account, moving a tab to another one and what that costs, and how the header shows an API key's estimated spend.
