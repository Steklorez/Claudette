# Plans, tasks and agents

On a big piece of work, Claude plans, keeps a list of tasks and hands pieces to subagents. This chapter covers how Claudette lets you follow that: the Tasks page with the plan and its versions, the docs Claude writes on claude.ai, and the agent map of what each subagent is doing.

Subagents run inside one session. To spread work over several tabs that you can step into, see [Threads](../threads/index.md).
