# Updates

Two things get updated: Claude Code, which Claudette runs in every tab, and Claudette itself. They update separately, each with a badge at the foot of the sidebar, and neither restarts a tab's Claude Code behind your back.

This chapter covers both, and what to do when an update doesn't go through. What's new in each version of Claudette is in the [changelog](https://github.com/dotBunny/Claudette/blob/main/CHANGELOG.md).
