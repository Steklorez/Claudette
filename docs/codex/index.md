# Codex

{% include unreleased.html %}

Deventry is made for Claude Code first, and Codex, OpenAI's coding agent, can run beside it, a tab at a time. A Codex tab works as a Claude Code tab does: the conversation and its cards, Changed files, permission prompts, History, subagents and threads. Claude Code stays the default: nothing changes for someone who never adds Codex.

This chapter covers adding Codex, working in a Codex tab and what differs from Claude Code's, and Codex's usage limits in the header.
