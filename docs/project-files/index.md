# Project files

{% include unreleased.html %}

Each project's folder group can have a Project Files tab: a tree of the project's folders and files, the files you open in tabs of their own, and Claude's changes marked where they are in the code. It's there for reading what Claude wrote, or fixing a line of it, without leaving the conversation. This chapter covers opening the tab, the explorer, finding files, the file tabs, editing and saving, how Claude's changes show, and how a file named in a reply opens here.

It's an editor, not an IDE: it has no completion, errors, debugging, building or source control.
