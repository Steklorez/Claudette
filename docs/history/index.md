# History and syncing

History lists your past sessions so you can pick one up again. The session library is Claudette's own copy of the sessions you choose to sync, kept in a folder you pick. Put that folder where a sync client such as Google Drive, Dropbox or OneDrive keeps it up to date, and your other machines can find the same sessions and continue them.

This chapter covers History, the library, syncing a tab, picking a session up on another machine, and keeping Claudette's settings the same across machines. The library only moves conversations. Your code moves the way it always does, through git or whatever you use.
